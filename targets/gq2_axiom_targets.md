Goal: prove the nine remaining axioms of the `G_{ℚ_2}` formalization (B1, B3c, B5, B6, B7, B8, B9, B10, B11a)
as theorems from reusable Tau Ceti theory, never as `ℚ_2`-only shortcuts. Every item below is a milestone
that an existing roadmap README actually states, grounded against STATUS.md and the open/merged PR record
as of 2026-09-02; what no roadmap covers is listed at the end and must not be authored against.
Ordering rule: within each area, attempt the first open `[ ]` item whose `needs` have all landed (`[x]`),
treating `[~]` items as not yet landed. Slugs are the principal declaration of the milestone in
kebab-case, or the id already carried by the PR that targets it; `needs` refers to slugs in this file
from any area. `serves` names only the axioms on whose proof path the milestone lies.
